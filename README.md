# 📄 PDF AI 어시스턴트

PDF 강의 교재를 보면서 AI에게 바로 질문할 수 있는 웹 앱입니다.  
설치 없이 브라우저에서 바로 사용합니다.

🔗 **[바로 사용하기](https://HMSeodam.github.io/aitutor)**

---

## ✨ 주요 기능

- PDF 뷰어 (페이지 이동, 확대/축소 — `Ctrl` + 마우스 휠로도 조절, 커서가 가리킨 지점이 제자리에 유지됨)
- **화면 필기 도구** — 커서 / 펜 / 형광펜 / 지우개, 4색(검정·형광노랑·형광핑크·형광파랑, 펜은 검정 · 형광펜은 노랑이 기본이며 도구별로 색을 따로 기억), 펜촉 굵기 5단계, 되돌리기·다시실행·전체삭제·보기숨기기
  - 필기는 페이지별로 저장되며, 확대/축소하거나 페이지를 옮겼다 돌아와도 그대로 유지됩니다
  - 단축키: `V` 커서 · `P` 펜 · `H` 형광펜 · `E` 지우개 · `1~4` 색 · `[` `]` 굵기 · `Ctrl+Z` 되돌리기 · `Ctrl+Shift+Z` 다시실행
- **메모장 (화이트보드)** — 필기 도구 막대의 `메모장` 버튼(지우개 오른쪽, PDF를 열면 함께 나타남). 별도 창에서 타이핑 + 그림판 필기
  - 도구: 선택·이동 / 펜 / 형광펜 / 텍스트 / 직선 / 화살표 / 사각형 / 원 / 지우개, 6색(펜·도형·글자는 검정, 형광펜은 노랑이 기본), 굵기 5단계
  - 쓴 내용은 객체로 남아 나중에 옮기거나 글자를 다시 고칠 수 있고, PNG로 저장됩니다
  - 창은 끌어서 이동·크기조절·최대화, 내용은 새로고침해도 유지됩니다
  - `Ctrl` + 마우스 휠로 글자 크기 조절 (입력 중이거나 글상자를 선택한 상태면 그것이, 아니면 기본 크기가 바뀜)
  - 단축키: `V P H T L A R O E` 도구 · `1~6` 색 · `[` `]` 굵기 · `Delete` 삭제 · `Ctrl+S` PNG 저장 · `Esc` 닫기
- 텍스트 드래그 선택 후 해당 부분 AI 질문 (PC·모바일 모두 지원)
- 질문 범위 선택 — 선택 영역 / 현재 페이지 / 전체 PDF
- 빠른 질문 버튼 — 핵심 요약 / 개념 설명 / 용어 풀이 / 예상 시험 문제
- AI 이미지 생성 — "이미지로 표현해줘" 요청 시 자동 생성
- 연속 대화 및 긴 응답 지원 (최대 65,536 토큰)
- PC + 모바일 반응형

---

## 🚀 사용 방법

1. [Google AI Studio](https://aistudio.google.com/apikey)에서 Gemini API 키를 발급받습니다.
2. 사이트 접속 후 **키 설정**에서 API 키를 입력합니다.
3. PDF 파일을 업로드합니다.
4. 텍스트를 드래그하거나 하단 입력창에 질문을 입력합니다.

---

## 🔒 개인정보 및 보안

- API 키는 브라우저 로컬 스토리지에만 저장됩니다.
- PDF 파일은 브라우저 내에서만 처리되며 서버에 업로드되지 않습니다.
- 질문 시 교재 텍스트가 Google Gemini API로 전송됩니다.
