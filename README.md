# 📄 PDF AI 어시스턴트

PDF 강의 교재를 보면서 AI에게 바로 질문할 수 있는 웹 앱입니다.  
설치 없이 브라우저에서 바로 사용합니다.

🔗 **[바로 사용하기](https://HMSeodam.github.io/aitutor)**

---

## ✨ 주요 기능

- PDF 뷰어 (페이지 이동, 확대/축소 — `Ctrl` + 마우스 휠로도 조절, 커서가 가리킨 지점이 제자리에 유지됨)
- **화면 필기 도구** — 커서 / 펜 / 형광펜 / 지우개, 4색(검정·형광노랑·형광핑크·형광파랑, 펜은 검정 · 형광펜은 노랑이 기본이며 도구별로 색을 따로 기억), 펜촉 굵기 5단계, 되돌리기·다시실행·전체삭제·보기숨기기
  - 필기는 페이지별로 저장되며, 확대/축소하거나 페이지를 옮겼다 돌아와도 그대로 유지됩니다
  - 단축키: `V` 커서 · `P` 펜 · `H` 형광펜 · `E` 지우개 · `1~4` 색 · `[` `]` 굵기 · `Ctrl+Z` 되돌리기 · `Ctrl+Shift+Z` 다시실행
- **메모장 (화이트보드)** — 필기 도구 막대의 `메모장` 버튼(지우개 오른쪽, PDF를 열면 함께 나타남). 별도 창에서 타이핑 + 그림판 필기
  - 도구: 선택·이동 / 펜 / 형광펜 / 텍스트 / 직선 / 화살표 / 사각형 / 원 / 지우개, 6색(펜·도형·글자는 검정, 형광펜은 노랑이 기본), 굵기 5단계
  - 쓴 내용은 객체로 남아 나중에 옮기거나 글자를 다시 고칠 수 있고, PNG로 저장됩니다
  - 창은 끌어서 이동·크기조절·최대화, 내용은 새로고침해도 유지됩니다
  - `Ctrl` + 마우스 휠로 글자 크기 조절 (입력 중이거나 글상자를 선택한 상태면 그것이, 아니면 기본 크기가 바뀜)
  - 단축키: `V P H T L A R O E` 도구 · `1~6` 색 · `[` `]` 굵기 · `Delete` 삭제 · `Ctrl+S` PNG 저장 · `Esc` 닫기
- **고전어 구조 분석 (TranslateDu 엔진 내장)** — 한문·현토 한문·일본 훈독 한문·팔리어·산스크리트어·티베트어를 드래그하면 언어를 자동 감지하고, 선택 메뉴의 `분석` 버튼으로 구조 분석
  - 한문: 절 분리 · 어절 분절 · 품사/기능 · 문장 성분 · 직역/의역 · 원문↔번역 대응 · 문법 포인트 · 불교학 참고 (TranslateDu 프롬프트·용어 사전·자기 검증 그대로)
  - 팔리어·산스크리트어·티베트어: 연성 해체 · 원형 · 형태(격·수·성·시제) · 복합어 · 대응 산스크리트어/한역어 · 직역/의역
  - 한국어 글 속의 한문 인용(「…」)이나 로마자 팔리어 낱말만 골라 분석, 감지 언어는 직접 바꿀 수 있음
  - 빠른 분석(API 1회) / 정밀 분석(자기 검증 포함 2회), 같은 구절은 저장해 두었다가 다시 씀
  - 대화창 요약 카드(행간 대역) + 전체 보기, HTML·JSON 저장, 메모장으로 보내기, 원문 고치기(옛 글꼴로 깨진 PDF 대비)
  - 대화창 위쪽 분석 버튼으로 원문을 직접 입력해 분석할 수도 있음
- **PDF 안에서 검색** — 헤더의 돋보기 또는 `Ctrl+F`, 결과 목록(쪽 + 앞뒤 문맥), 띄어쓰기 무시 · 이체자(爲=為 등) 포함 옵션, 강희부수·호환 한자 자동 대응, 자모로 풀린 한글·팔리어 장음 부호 자동 대응
  - 입력을 멈추면 찾음(한글 조합 중에는 기다림). 휴대폰·태블릿은 입력하는 동안 건수만 보여 주고, 키보드의 `검색` 키를 누르면 결과로 이동
- **선택 메뉴** — 드래그하면 질문 · 번역(분석) · 풀이 · 형광펜 · 인용 복사(출처 포함) · 메모장
- **휴대폰·태블릿 최적화** — 두 손가락 확대, 레티나 선명도, 3단계 하단 대화창, 접어 두는 필기 도구, 애플 펜슬 전용 그리기
- 텍스트 드래그 선택 후 해당 부분 AI 질문 (PC·모바일 모두 지원)
- 질문 범위 선택 — 선택 영역 / 현재 페이지 / 전체 PDF
- 빠른 질문 버튼 — 핵심 요약 / 개념 설명 / 용어 풀이 / 예상 시험 문제
- AI 이미지 생성 — 준비 중 (다음 버전에서 추가 예정)
- Gemini 모델 목록 자동 갱신 (새 모델 추가 · 퇴역 모델 삭제, 아래 참고)
- 연속 대화 및 긴 응답 지원 (최대 65,536 토큰)
- PC + 모바일 반응형

## 🚀 사용 방법

1. [Google AI Studio](https://aistudio.google.com/apikey)에서 Gemini API 키를 발급받습니다.
2. 사이트 접속 후 **키 설정**에서 API 키를 입력합니다.
3. PDF 파일을 업로드합니다.
4. 텍스트를 드래그하거나 하단 입력창에 질문을 입력합니다.

## 🤖 Gemini 모델 자동 관리

모델 선택 목록은 `models.json`에서 읽습니다. GitHub Actions가 매주 월요일 오전 9시경(한국 시간) 이 파일을 점검합니다.

- **새 모델 추가** — Gemini API 모델 목록에서 새 안정판(Flash · Flash Lite)을 찾아, 실제로 짧게 호출해 보고 쓸 수 있으면 넣습니다. preview·실험판·유료 전용 모델은 넣지 않습니다.
- **퇴역 모델 삭제** — 구글의 [지원 중단 일정](https://ai.google.dev/gemini-api/docs/deprecations)에서 종료일이 3주 안으로 다가온 모델, 호출하면 "더 이상 쓸 수 없음"이 돌아오는 모델, 새 모델로 자동 전달되는 옛 이름을 뺍니다.
- 계열마다 최신 2개씩 두고, 기본 모델은 가장 새 Flash입니다. **2.5 Flash는 `pin`으로 고정**되어 구글이 실제로 종료할 때까지 목록에 남습니다. 종료일이 잡힌 모델은 목록에 `(27.5 종료)`처럼 표시됩니다.
- 앱에서도 한 번 더 지킵니다: 질문 중 모델이 예고 없이 끊기면 다음 모델로 바꿔 자동으로 다시 보냅니다.

규칙은 `models.json`의 `rules`에서 바꿀 수 있습니다 (`perFamily` 계열당 개수, `pin` 늘 남길 모델, `exclude` 넣지 않을 모델 등).

## 🔒 개인정보 및 보안

- API 키는 브라우저 로컬 스토리지에만 저장됩니다.
- PDF 파일은 브라우저 내에서만 처리되며 서버에 업로드되지 않습니다.
- 질문 시 교재 텍스트가 Google Gemini API로 전송됩니다.
